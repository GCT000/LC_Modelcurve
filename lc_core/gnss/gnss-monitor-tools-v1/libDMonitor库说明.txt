库名：libDMonitor.so
版本：v2.0.6
数据格式及存放路径说明:
	数据以RTCM格式存放，路径为:1.自定义根路径\YYYY\DOY\HH\站名.YYYYDOYbinRTCM3
							 或2.自定义根目录\站名.自定义后缀名
支持调用函数：
	void* startMonitor(void* arg)
	后解算启动函数。形参：实例化mInfo对象的地址。
							mInfo定义：typedef struct monitorInfo {
											char configStr[600];    /* command string invoked afterwards */
											char errMsg[1000];
											char solBuf[400];
										}mInfo;
							声明对象时需初始化configStr字符串,格式为:calculateMode@fileMode@timeStart@timeEnd@sample@VRSIndex@roverFileName@baseFileName@filesDirectory@fileExtension@broadcastFile@navsys@outFile@fileStorageType@outputNumbers@fixRateThreshold@rb-x@rb-y@rb-z
							/* calculateMode  :0:spp; 2:kinematic; 3:static */
							/* fileMode       : 1-rtcm3; 2-rinex */
							/* timeStart */
							/* timeEnd */
							/* sample */
							/* VRSIndex  : 0-false; 1:true */
							/* roverFileName */
							/* baseFileName */
							/* filesDirectory  : 数据存储自定义根目录 */
							/* fileExtension */
							/* broadcastFile full name */
                                                        /* navsys */
							/* outFile full name */
							/* fileStorageType  0:single file; 1:hour file */
							/* outputNumbers  0:all; 1:single */
							/* fixed threshold  0~1 */
							/* rb-x */
							/* rb-y */
							/* rb-z */
							示例:"3@1@2023/04/21 09:00:00@2023/04/21 11:00:00@15@0@PSYCMM075@PSYCMM072@D:\\calculate\\minggudaohang\\算法调试数据\\@@@45@@1@1@0.75@@@"
							示例说明:利用监测站PSYCMM075和基准站PSYCMM072在2023/04/21 09:00:00至2023/04/21 11:00:00的数据进行静态解算,文件类型为RTCM3,采样频率为15s,基站非VRS.
							         基站文件和监测站文件都按照小时文件存储,此处文件路径存储在D:\\calculate\\minggudaohang\\算法调试数据\\YEAR\\DOY\\HOUR\\,后缀名默认为YYYYDOYbinRTCM3
							
							输出结果存储于solBuf,格式为:timeStart timeEnd dposMax dposAvg dposSTD epochRate(u) epochRate(r) fixRate E N U stat solutionType nSat isMoved tiRover tiBase nRover nBase obsFlag navFlag elapsedTime
							/* timeStart  :YYYY/MM/DD hh:mm:ss */
							/* timeEnd    :YYYY/MM/DD hh:mm:ss */
							/* dposMax    :相邻历元间位移估计最大值 */
							/* dposAvg    :相邻历元间位移估计平均值 */
							/* dposSTD    :相邻历元间位移估计STD值 */
							/* epochRate(u)  :epoch rate of user(0~1) */
							/* epochRate(r)  :epoch rate of reference(0~1) */
							/* fixRate    :固定率,高于75%输出固定解,否则不输出 */
							/* E */
							/* N */
							/* U */
							/* stat       :解算结果状态(Fixed;Float;None) */
							/* solutioType   :1~4, 1 is available, 4 is inavailable */
							/* nSat       :平均可用卫星数 */
                                                        /* isMoved    :是否位移 */
                                                        /* tiRover    :监测站采样间隔(s) */
							/* tiBase     :基准站采样间隔(s)       */
							/* nRover     :监测站可用历元数 */
							/* nBase      :基准站可用历元数 */
							/* obsFlag    :观测值标志,0为正常*/
							/* navFlag    :星历值标志,0为正常*/
							/* elapsedTime:解算总耗时 */
							示例:2023/08/22 16:00:00 2023/08/22 20:00:00 0.0000 0.0000 0.0000 0.9369 0.9688 0.9906 -832.1710 1651.7705 17.2839 Fixed 1 7 0 15 15 930 951  0  0 1.1s
